# Theme: Token Grid（分词格）

为「推理工程笔记」定制。灵感来自本站首篇的核心配图——一次 JSON 回复被切成 17 个
token 方块，其中只有 3 个是答案。把这个「离散方块」变成整站的结构语言。

## 调色板

| 名称 | 浅色 | 深色 | 角色 |
|---|---|---|---|
| Paper 暖纸 | `#FAF8F3` | `#0E1116` | 页面底色 |
| Ink 蓝石板 | `#1A2230` | `#EDEFF3` | 标题、强调文字 |
| Body 正文 | `#3A4351` | `#C3C9D4` | 正文 |
| Dim 弱化 | `#8B94A3` | `#7D8797` | 元信息、图注 |
| Accent 深松绿 | `#0E7C63` | `#6FC9AA` | 链接、主色、章节标记 |
| Mint 薄荷 | `#A8E0D1` | `#17362D` | 方块填充（取自配图） |
| Peach 蜜桃 | `#FFB4A2` | `#3A2620` | 强调方块（配图里「答案」的颜色） |
| Lilac 淡紫 | `#C9C4F0` | `#262340` | 次要方块 |
| Line 分隔 | `#E7E4DC` | `#232833` | 细线、边框 |

中性色统一带主色的蓝绿偏向，不用纯灰。

## 字体

- **标题 / 正文（中文）**：`-apple-system, "PingFang SC", "Noto Sans SC", sans-serif`
  中英混排，标题用 800 字重 + `-0.03em` 字距收紧。
- **等宽（个性所在）**：`"IBM Plex Mono", ui-monospace, Menlo, monospace`
  用于日期、章节序号、标签、token 方块、代码、阅读时长。这是本主题露脸的字体，
  不藏在代码块里。
- 不使用拉丁衬线做标题：本站标题多为中英混排，衬线拉丁与黑体中文同行会打架。

## 结构母题：token 方块

统一的圆角小方块（`border-radius: 6px`，内边距 `.16em .5em`，等宽字），用于：

- 文章标签
- 章节序号（`01` `02` …）
- 目录条目的编号
- 代码块的语言标签
- 正文里的行内代码

方块的填充色按语义分：默认淡墨底；主色底用于「当前」状态；蜜桃底用于强调。

## 型号与间距

正文 17px / 1.9，测量宽度 40rem（约 40 个汉字/行）。
标题层级：2.6rem → 1.3rem → 1.05rem，均 `text-wrap: balance`。
分区之间 3.6rem，段落之间 1.25rem。

## 适用

深度技术长文、复现实验报告、带大量图表的工程笔记。
